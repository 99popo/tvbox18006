# 应用于影视仓或TVBOX等安卓壳子的接口文件 

## 命名为：fan.json

是以“饭太硬”作者的接口文件为基准，删除全部网盘，删除全部儿童内容，删除一部分B站，删除一部分测试不顺的site 
另存spider文件，为fan-spider.jar ，覆盖内容，并另外记录MD5值。

源接口地址为：
http://www.饭太硬.art/tv 
http://www.饭太硬.cc/tv 
http://www.饭太硬.net/tv 

格外添加内容有：个别live
